# 键盘/键帽测试知识库

本目录用于 RAGFlow PoC 阶段导入测试。内容是开发阶段自编的店铺/商品知识文档，不代表真实商家政策。

建议导入顺序：

1. `01_键盘商品规格与选购指南.txt`
2. `02_键帽材质工艺与兼容性FAQ.txt`
3. `03_机械键盘售后与保修政策.docx`
4. `04_发货包装与退换货规则.pdf`

建议在 RAGFlow 中创建两个 dataset：

- `键盘商品知识库`：导入规格、选购、键帽、兼容性相关文档。
- `键盘售后知识库`：导入售后、保修、发货、包装、退换货相关文档。

PoC 阶段也可以先全部导入同一个 dataset，便于快速验证检索效果。
