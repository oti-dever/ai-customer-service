# 键盘实拍图与图片素材说明

适用店铺：青轴客制化键盘店
适用场景：客户询问是否有实拍图、细节图、配色图、商品外观图，或需要客服发送键盘图片辅助确认。
版本：2026-07-03

## 一、图片素材总体说明

当前知识库素材目录中已经准备了 K87、K98、K68 三类键盘的测试图片素材，可用于开发阶段的图片知识库检索、建议附图、人工确认发送和自动回复附图测试。

当客户问“有实拍图吗”“有没有 K87 键盘实拍”“发个 K98 图片看看”“K68 细节图有吗”等问题时，客服不应回答“没有图片”或“暂时没有实拍图”。应优先说明“有的，可以发您看一下”，并根据客户咨询型号匹配对应图片素材。

- keyboard_k87_inphic_black_red_front.png：K87 黑红配色正面图，适合客户询问黑色、黑红、RGB、87 键/TKL 布局外观时发送。
- keyboard_k87_inphic_gray_white_front.png：K87 灰白配色正面图，适合客户询问浅色、白色、灰白、办公风格外观时发送。

亲，有的，K87 这边有黑红配色和灰白配色的实拍/商品图，我可以发您看一下外观效果。

## 五、客服回复规则

1. 客户明确要图片时，如果图片素材库命中对应型号，应回复“有的”，并建议附图。
2. 文本回复不要和图片推荐冲突，不能一边说“没有实拍图”，一边又发送图片。
3. 如果客户只问某个型号图片，优先匹配同型号图片，不要发送其他型号图片。
4. 如果客户没有指定型号，可以先简单介绍 K87、K98、K68 都有图片可参考，再询问客户想看哪一款。
5. 如果素材图不是正式商拍图，回复时可使用“商品图”“参考图”“外观图”这类稳妥说法，避免过度承诺“百分百实拍”。

## 六、自动回复附图建议

当客户最新消息明确询问图片、实拍图、外观图、细节图、配色图时，可以在文字回复后附上对应图片素材。自动回复应优先发送文字说明，再发送图片，避免客户只收到图片不知道含义。

示例：

客户：有 K87 键盘实拍吗？

建议回复：亲，有的，K87 这边有黑红配色和灰白配色的外观图，我先发您看一下参考效果。

建议附图：优先发送 keyboard_k87_inphic_black_red_front.png 或 keyboard_k87_inphic_gray_white_front.png。
